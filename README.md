# hackathon-heart-ui

Small React + Vite UI for the HEART hackathon project.

## Quickstart — pull, install, run (macOS / zsh)

1. Clone the repository (replace <remote> if you use a different remote):

```bash
git clone git@github.com:bhavinkmistry/hackathon-heart-ui.git
cd hackathon-heart-ui
```

2. Install dependencies (uses npm):

```bash
npm install
```

3. Start local dev server (hot-reloads):

```bash
npm run dev
# open http://localhost:5173
```

4. Build for production and preview:

```bash
npm run build
npm run preview
# preview runs a small static server (default port 4173)
```

## Notes & troubleshooting

- Node: this project was developed with Node 18+. Use nvm or your preferred node manager if you need to switch versions.
- If the dev server port is already in use, Vite will try the next port. You can force a host/port with:

```bash
npm run dev -- --host --port 5173
```

- If you see an npm audit warning, it's usually safe for local dev. To address advisories, upgrade dependencies carefully (for example, Vite v7+ fixes a reported moderate advisory but is a semver-major change).
